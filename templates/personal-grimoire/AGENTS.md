# AGENTS.md

This repository is a Grimoire routing map. It contains no project knowledge and
should stay small enough to read in full — or paste into a chat window that has
no filesystem access.

## How to use it

1. Read `GRIMOIRE.md`.
2. Read `projects.yaml`.
3. Resolve the project I named to its `architecture` repository.
4. Open that repository and follow its `AGENTS.md`.

If the project I named is ambiguous or missing from `projects.yaml`, list the
projects you found and ask. Do not guess.

## What does not belong here

Project knowledge, notes, decisions, session records, or drafts. All of that
belongs in the project's architecture repository. This file and `projects.yaml`
are a map, not a warehouse — if this repository is growing, something is in the
wrong place.

## Privacy

This repository is private and names every project I work on, including
unannounced ones. Do not copy its contents into shared, public, or third-party
destinations without asking.
